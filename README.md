# AFTER PARKER — Jazz / Bass / Listening Lab

チャーリー・パーカー以降のジャズを、**歴史・理論・ベースの実践・業界文化・録音美学・実際の耳**から学ぶ日本語教材です。`chanwata/bass-study` と `chanwata/vocal-study` の「各レッスンで学びが完結する」「実際に聴く」「演奏に持ち帰る」UX方針を引き継ぎました。

## 実装済み

- **14レッスンを長文版へ増補**。各レッスンで歴史・系譜、技法分析、主要人物3人以上の解説、3周する聴取ガイド、ベース実践実験、制作・文化の小話、出典を同一ページに配置。初版の概要に詳細解説を追加。
- 和声の学習は **Web Audio API** のピアノ風シンセで、ヴォイシング・進行・ベース音をアプリ内再生。音色は教材用の合成音であり、実際のコンサート・スタジオ録音や本物のピアノの音ではありません。
- **14章にオリジナルの演奏用音列43本、段階別の実践課題42本、比較対象の録音28件を追加**。1拍単位のベース、半拍の先取り、実際の休符、低音と上声の独立した発音タイミングをブラウザで再生。75/100/125%の速度変更、2回リピート、練習チェックと端末保存。
- 10問の音声A/B耳トレ。回答まではコード構成音を表示せず、回答後に根拠、構成音、実機ピアノでの再現方法を表示。
- 2オクターブのタッチ鍵盤と、So WhatヴォイシングのベースD/C/F比較、Fmaj7の11/#11比較。
- 手元のピアノで弾くモード。コードの音名を参照して実機で再現。**マイクからの自動聴音や演奏採点は未実装**。
- 4レッスン（So What、Gloria’s Step、Giant Steps、Acknowledgement）は確認した公式チャンネルのYouTube音源をページ内で埋め込み再生できます。残りはYouTube録音検索リンクから権利者側で聴けます（検索結果の録音の同一性は要確認）。**著作権のある原盤を教材内で再配布しません**。
- レッスン完了、ノート、耳トレ回答の端末ローカル保存。JSONエクスポートと安全なスキーマ検証付きインポート。
- iPhone等で使いやすいレスポンシブ構成。外部JSや依存パッケージ不要。
- GitHub ActionsからGitHub Pagesへの自動デプロイ。mainへのpushで教材データ整合性チェックを実施して公開。

## 使い方

1. `# /lesson/01` にアクセスしてレッスンを選ぶ。
2. 指定アルバムを外部サービスで聴き、ポイントを確認。
3. 「音で確かめる」で比較音をアプリで再生。または手元のピアノに書かれた音名を弾く。
4. ベース演奏課題で試す。確認クイズを解き、メモを書く。完了ボタンを押す。
5. 耳トレタブで先にA/Bを聴き、構成音を表示する前に答える。

**ブラウザ音声について**：iOS Safariでは利用者のタップ後にAudioContextが始まります。ブラウザ、端末、ヘッドホンにより聞こえ方は異なります。合成音の低音はスマホの内蔵スピーカーだと聴きづらいためイヤホン推奨です。

## GitHub Pagesでの公開

この教材は [chanwata/jazz-powerup](https://github.com/chanwata/jazz-powerup) の `main` にアップロード済みです。GitHub Actions `Bootstrap Jazz Powerup` で自動テストと静的ビルドは成功しました。

**初回のみ必要な設定（リポジトリ管理者）：**

1. [Settings → Pages](https://github.com/chanwata/jazz-powerup/settings/pages) を開く。
2. **Build and deployment → Source = GitHub Actions** に変更する。
3. [Actions → Bootstrap Jazz Powerup](https://github.com/chanwata/jazz-powerup/actions/workflows/bootstrap.yml) から `Run workflow` を実行するか、失敗した実行の `Re-run jobs` を選ぶ。
4. 成功後、`https://chanwata.github.io/jazz-powerup/` で公開。

`main` への変更は `.github/workflows/bootstrap.yml` がテスト・ビルド・Pages公開を自動実行します。公開URLはActionsのdeployが成功するまでは有効ではありません。

## 自動化とテスト

`.github/workflows/bootstrap.yml` でNode.js標準 `node --test` を実行してから、`npm run build` で最小の静的サイトを `dist/` にコピーして、ActionsのPages artifactをデプロイします。ビルドに外部ライブラリは不要。Node.js 22以上推奨。

## 教材の立場

- 解釈と史実は区別。譜面・セッションの全詳細を再現する教材ではありません。
- 演奏家の実際の発言と本教材の音楽的解釈を混同しない。
- 耳トレ問題は短いオリジナルの教材用ヴォイシング。録音音源や楽曲の旋律そのものではありません。
- 日本語の呼称、コードネーム、テンションの記法には複数の慣習があります。
- 本教材は作成者の学習用途。いかなる音源の権利者・レーベルとも提携していません。

## 演奏練習の増補版

各レッスンの「PRACTICE WORKSHOP」では、実際の原盤ではない**教材用の独自フレーズ**を複数の案で比較。各音の発音時刻は小節内の拍数で表し（@0=1拍目、@1=2拍目、@3.5=4拍裏）、音価の指定（/2.0）や休符（_）もある。音色の合成は実際のジャズ録音やアコースティックの再現ではない。テンポ変更とリピート、実機で弾く3段階の課題、実録音の比較聴取、自己チェックを追加した。練習済みチェックは他の学習履歴と同様にローカル保存され、JSONで移行できる。

## 学習ダッシュボード（2026-10）

- トップページを `#/home` に変更。既存のレッスン・鍵盤・耳トレへワンクリックで移動。
- 14章の完了数、42実践課題の完了数、耳トレ回答・正答数、直近7日の活動日数、連続学習日数、週の目標をローカル記録から計算。表示する活動履歴はこの機能の導入以降の操作から記録し、古い進捗の学習日を推定しません。
- 復習カードはクイズをまず頭で回答し、その後に解説を開いて『思い出せた／もう一度』を自己評価。復習間隔は1/3/7/14/30日の簡易スケジュール（適応学習の精密な測定ではありません）。
- 5/15/25分の練習プランと実践済みボタン。セッション時間は自己申告であり、自動計測ではありません。
- 端末内の既存進捗とノート・耳トレは維持。新しい活動履歴や復習予定もJSONでエクスポート・インポート可能。
- 設計の根拠は想起練習と分散学習に関する学習科学レビュー：Dunlosky et al. (2013), Psychological Science in the Public Interest, https://doi.org/10.1177/1529100612453266 。神経伝達物質の測定や脳状態の推定は行いません。
