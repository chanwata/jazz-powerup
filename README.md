
## 学習メモに応じた教材の進化（Learning Memory）

- 各レッスンの冒頭に **PERSONAL LEARNING** を追加。これまでのメモ・学習理解の自己評価（「まだ曖昧／理解した／弾いて検証した」）・練習チェック・クイズ誤答から、次に提示する説明・確認質問・音声／ベース課題を出し分けます。既存の14章の史実や譜面の原典は書き換えません。まずはルールベースの個別化なので、自由文を深く意味理解したAIであると誤認しないでください。
- **「学習ログ」**を追加。既存のブラウザ内メモを表示し、本人が明示的に同期ボタンを押したときだけGitHubへ進捗・メモを保存／取得できます。
- **個人メモの保存先は、利用者が別途作る非公開リポジトリ `chanwata/jazz-powerup-memory` に固定。** 公開サイトの `chanwata/jazz-powerup` には保存しません。GitHub APIの応答が `private:true` でない場合は保存を拒否。
- ブラウザの同期には非公開リポジトリだけに権限を限定したFine-grained PATが必要。Tokenはタブ内のJS変数だけで保持し、localStorageやバックアップに含めません。別端末の変更を上書きしないSHA照合あり。取込前に自分の端末のバックアップを推奨。
- ChatGPTのGitHubコネクタが非公開リポジトリを読める場合、利用者の依頼によって `learning/state.json` の学習内容を分析し、`learning/tutor-feedback.json` へ具体的な個別解説・聴音・演奏課題を書き戻せます。アプリの「講師コメントを取得」で各章に追加表示します。自動的な外部LLM API呼出しはありません。
- 初回設定、トークンの安全な運用、同期時の制約、レビューのデータ形式は [docs/learning-memory.md](docs/learning-memory.md) にまとめました。
